# Trust and authority boundaries

- Knowledge ≠ authorization. Attestation ≠ truth or current applicability.
- Institutional provisions ≠ self-issued grants. Competence ≠ delegated authority.
- Declaration ≠ policy permission. Policy permission ≠ completed effect.
- Execution acknowledgement ≠ independent destination observation or verification.
- Replay reconstruction ≠ independent replayed effect; evidence validation ≠ reviewer approval.
- ISS cognitive output is proposal data only; no implied trusted execution or imported private logic.
- Local synthetic positive tests ≠ production security, fleet stop or enterprise readiness.
